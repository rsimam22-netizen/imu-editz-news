বিজ্ঞাপন ব্যবস্থাপনা

Header, Footer, Sidebar এবং Popup বিজ্ঞাপন এখান থেকে নিয়ন্ত্রণ করুন।

📌 Header Advertisement
ওয়েবসাইটের Header-এর নিচে বিজ্ঞাপন দেখাবে।
Header Advertisement চালু করুন চালু করলে Header বিজ্ঞাপন Website-এ দেখা যাবে।

Ad Network-এর HTML/JS code অথবা একটি URL দিন।
📌 Footer Advertisement
Footer-এর উপরে বিজ্ঞাপন দেখাবে।
Footer Advertisement চালু করুন Footer বিজ্ঞাপন Website-এ দেখাবে।


📌 Sidebar Advertisement
Website-এর Sidebar-এ বিজ্ঞাপন দেখাবে।
Sidebar Advertisement চালু করুন Sidebar বিজ্ঞাপন চালু / বন্ধ করুন।

🪟 Popup Advertisement
Visitor Website-এ প্রবেশ করার পর Popup বিজ্ঞাপন দেখাবে।
Popup Advertisement চালু করুন Popup বিজ্ঞাপন চালু / বন্ধ করুন।

5000 = ৫ সেকেন্ড

ভিডিও নিউজ

🎬 Video News Settings
Video News চালু করুন চালু করলে Homepage-এ ভিডিও নিউজ দেখানো যাবে।

YouTube → Share → Embed থেকে পাওয়া iframe code এখানে দিন।
